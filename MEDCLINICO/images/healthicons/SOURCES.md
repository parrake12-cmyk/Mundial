# Health Icons

Las imágenes de esta carpeta vienen del repositorio público `resolvetosavelives/healthicons`:

https://github.com/resolvetosavelives/healthicons

Fuente usada en este proyecto:

`public/icons/svg/outline/body/*.svg`
