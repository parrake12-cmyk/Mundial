# Calidad de informacion en enfermedades

Agregar referencias solo mejora la calidad si cada fuente cumple una funcion clara. La ficha no debe ser "un resumen con links"; debe ser una sintesis revisada contra varias capas.

## Niveles de calidad

### Nivel 0: texto interno

- Tiene definicion, sintomas y pruebas.
- No tiene fuente concreta por seccion.
- Sirve como borrador, no como ficha confiable.

### Nivel 1: fuente de resumen

- Tiene fuente clara tipo MedlinePlus, MSD Consumer, OMS o CDC.
- Mejora lenguaje, sintomas principales y explicacion general.
- Todavia puede faltar fisiopatologia y clasificacion.

### Nivel 2: fuente teorica

- Tiene fuente de libro o referencia clinica: NCBI Bookshelf, StatPearls, Clinical Methods, Health Alterations o MSD Professional.
- Mejora fisiopatologia, evaluacion, diagnostico diferencial y razonamiento.

### Nivel 3: clasificacion y sinonimos

- Tiene Disease Ontology, ICD-11, Orphanet o GARD segun aplique.
- Mejora busqueda, familias de enfermedades, sinonimos y consistencia de nombres.

### Nivel 4: especialidad

- Tiene fuente especifica por area:
  - NCI PDQ para cancer;
  - NIDDK para renal, digestivo, diabetes y endocrino;
  - NHLBI para cardio, pulmon, sangre y sueno;
  - NIAMS para piel, huesos, musculos y articulaciones;
  - NINDS para neurologia;
  - NEI para ojo;
  - GARD/Orphanet para raras.
- Aqui la ficha empieza a dejar de sentirse generica.

### Nivel 5: lista para ensenar

- Tiene resumen claro.
- Tiene teoria.
- Tiene clasificacion.
- Tiene fuente por especialidad cuando aplica.
- Tiene recurso anatomico o visual.
- Tiene nota de revision.
- Puede tener caso y preguntas, pero no depende de ellos.

## Regla practica

Para considerar una enfermedad "buena", minimo debe tener:

1. una fuente de resumen;
2. una fuente teorica;
3. una fuente de clasificacion o especialidad;
4. fecha o estado de revision.

## Que aporta cada referencia

| Tipo de fuente | Aporta calidad en |
| --- | --- |
| MedlinePlus / OMS / CDC | claridad, sintomas, prevencion, lenguaje educativo |
| NCBI Bookshelf / StatPearls / Clinical Methods | profundidad medica y razonamiento |
| MSD Professional | contraste clinico rapido |
| Disease Ontology / ICD-11 | estructura, familias y nombres consistentes |
| NCI / NIDDK / NHLBI / NIAMS / NINDS / NEI | autoridad por especialidad |
| PubMed / Europe PMC | busqueda de revisiones y literatura reciente |
| OpenStax / Servier / BioIcons | anatomia, fisiologia y visuales |

## Decision editorial

No copiar grandes bloques de texto. Usar las fuentes para verificar, resumir, contrastar y citar. El valor del proyecto debe estar en la sintesis didactica, no en pegar contenido externo.
